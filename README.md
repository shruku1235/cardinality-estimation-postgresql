# cardinality-estimation-postgresql
Exploring cardinality estimation errors in PostgreSQL across JOB and TPC-H Benchmarks

All files used for this project are included. All .sql files with an 'a' in the name
correspond to JOB queries, while the remaining .sql files are TPC-H queries. There
are several .py files, and if "tpch" is in the file name, it was used for the TPC-H
queries, and the JOB queries if not.
